# Privacy notice

Effective 26 October 2026 · HEIC2JPG 1.2.0 and later · Developer: KULAM · Contact: heic2jpg@kulam.my.id

## Photo conversion

HEIC/HEIF decoding and JPEG encoding run locally. HEIC2JPG does not upload photos for conversion. Input paths, image bytes, EXIF/GPS and output files are used on your device to perform the conversion. Metadata preservation is enabled by default and can retain location information in output JPEGs; disable it before conversion if you do not want to copy metadata. Keep original files for archival purposes.

## Local storage

Preferences and window dimensions are stored in your Windows user-data directory. The conversion queue is session-only. Temporary conversion files are created beside the destination and cleaned up after normal completion. Reports exported through Save conversion report may contain local paths and error messages; you choose where to save and whether to share them. The application has no analytics, advertising identifier, account system, or photo-upload service.

## Update checks

When Automatically check for updates is enabled, the installed application contacts GitHub Releases at startup and approximately every six hours while running, when it is not converting photos. GitHub receives ordinary request information such as your IP address and HTTP headers. No photo, EXIF, filename, conversion queue or saved preference is included. GitHub's own privacy terms apply. You can disable automatic checking in About & updates and check manually. Downloads and restart/installation require an explicit action; the app does not install updates automatically when you quit.

## Problem reports

The in-app form uses only text you enter. Basic diagnostics are optional and limited to application version, Windows version, architecture, Electron version and build type. It does not collect photos, EXIF, paths, preferences or conversion logs automatically.

Open email draft passes the entered report to your default email application using a mailto link; it does not send email itself. GitHub issue opens a draft in your browser; you decide whether to submit it, and public issues are visible to others. Copy report writes the report to your clipboard. Avoid including personal information or private photo metadata. Use email for security concerns.

## External services and contact

Links to www.kulam.my.id and GitHub open only when selected. External services have their own privacy practices. Support email delivery, retention and deletion depend on the developer's mailbox and the email services involved; contact heic2jpg@kulam.my.id for privacy requests. Reports are used for support and issue investigation. Do not send sensitive images unless you have agreed on an appropriate private channel.
