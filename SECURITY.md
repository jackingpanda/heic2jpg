# Security reporting

Report suspected vulnerabilities privately to **heic2jpg@kulam.my.id**. Include the HEIC2JPG version, affected feature, reproduction steps and a non-sensitive example where possible. Do not publish exploit details or private photos in public issues before the developer has had a reasonable opportunity to investigate.

Do not include passwords, access tokens, personal photo metadata or full personal file paths. The in-app Report a problem form supports private email drafts and does not attach files automatically. No guaranteed response time or bug bounty is promised.

Official Windows installers are currently unsigned. Download official assets from https://github.com/jackingpanda/heic2jpg/releases. Update checks use that repository; downloads are checked against the published update manifest. A checksum is an integrity check, not a replacement for a publisher's code-signing certificate.
